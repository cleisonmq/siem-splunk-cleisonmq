# siem-splunk-cleisonmq

Documentação sobre a implementação de um SIEM com Splunk: instalação e configuração do agente (Universal Forwarder), gestão dos ficheiros monitorizados e envio de alertas por e-mail.

## O que vai encontrar

- [agente-slpunk/](agente-slpunk/): instalação e configuração do Splunk Universal Forwarder num cliente Linux, e ligação ao servidor Splunk Enterprise.
- [dashboards/](dashboards/): dashboards do Splunk.
- [imagens/](imagens/): imagens de apoio à documentação.

## A quem se destina

- A quem esteja a instalar ou configurar um ambiente Splunk (SIEM) num servidor Linux.
- A quem administra esse ambiente e precisa de gerir o que é monitorizado.
- A quem precisa de um guia passo a passo para pôr um agente a enviar dados para o Splunk.
- A quem precisa de configurar o envio de alertas por e-mail.
